# Mobile App Support

Tachyon Cowork targets mobile as a chat-first Tauri app with a desktop-only
tooling layer. The mobile build keeps the core assistant loop available while
gating host filesystem, process, and sandbox features that do not belong on
iOS/Android.

## Mobile Scope

- Sign in and token refresh
- Model selection
- Chat send/receive
- Session history
- Mobile file attachment through the platform picker
- Full-screen artifact and canvas viewing on small screens
- Basic settings that do not depend on local host capabilities

## Native Behavior

- OAuth uses the existing `tachyon-cowork://auth/callback` deep link in Tauri.
- File attachments use `@tauri-apps/plugin-dialog` plus `@tauri-apps/plugin-fs`
  in Tauri and an invisible `<input type="file">` on web.
- Notifications stay available through the Tauri notification plugin, but no
  mobile-only notification workflow is enabled yet.
- Auth state remains in the existing browser storage path. A platform
  keychain/keystore migration should be a later hardening task if App Store or
  enterprise policy requires stronger at-rest protection.

## Desktop-only Features

These features are gated to Tauri desktop:

- Local workspace folder selection
- Work folder pages and project custom instructions backed by host files
- Local file tools: search, organize, duplicate detection, disk usage
- Host command execution
- Sandbox code execution
- MCP stdio and child-process transports
- Global shortcuts
- Self updater and process relaunch
- OS file-manager integration such as showing a file in Finder

## Current Implementation Notes

- `src/lib/tauri-bridge.ts` exposes `isTauriDesktop()` and `isTauriMobile()`.
- `src/App.tsx` only shows file tools and work-folder routes on Tauri desktop.
- Settings hides MCP configuration outside Tauri desktop.
- Artifact and canvas panels become full-screen overlays on mobile.
- `vite.config.ts` respects `TAURI_DEV_HOST` for Tauri mobile dev server/HMR.
- `src-tauri/src/lib.rs` keeps updater, process relaunch, global shortcuts, and eager MCP connection on desktop only.
- Sandbox and trash dependencies are excluded from iOS/Android builds.
- `src-tauri/gen/` is generated by Tauri and ignored by git. Run the platform
  init commands locally when the generated Xcode/Android Studio projects are
  missing.

## Commands

```bash
npm run tauri -- ios init --ci
npm run tauri -- android init --ci
npm run tauri -- ios build --debug --target aarch64-sim --ci
JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home" \
CC_aarch64_linux_android="$ANDROID_HOME/ndk/28.2.13676358/toolchains/llvm/prebuilt/darwin-x86_64/bin/aarch64-linux-android34-clang" \
CXX_aarch64_linux_android="$ANDROID_HOME/ndk/28.2.13676358/toolchains/llvm/prebuilt/darwin-x86_64/bin/aarch64-linux-android34-clang++" \
AR_aarch64_linux_android="$ANDROID_HOME/ndk/28.2.13676358/toolchains/llvm/prebuilt/darwin-x86_64/bin/llvm-ar" \
CARGO_TARGET_AARCH64_LINUX_ANDROID_LINKER="$ANDROID_HOME/ndk/28.2.13676358/toolchains/llvm/prebuilt/darwin-x86_64/bin/aarch64-linux-android34-clang" \
npm run tauri -- android build --debug --apk --target aarch64
```
